JSON Format Instructions

  • The organization structure must be in valid JSON format
  • Use "name" for officer/section names
  • Use "rank" for officer ranks/designations
  • Use "children" array for subordinate officers/sections
  • Ensure all strings are in double quotes
  • Don't forget commas between items (but not after the last item)
  • Click "Validate JSON" to check for errors before saving
Example Structure: 
{
  "name": "Commandant",
  "rank": "DIG",
  "children": [
    {
      "name": "Second-in-Command",
      "rank": "Addl. SP",
      "children": [
        {
          "name": "Company 1",
          "rank": "SDPO",
          "children": []
        },
        {
          "name": "Company 2",
          "rank": "SDPO",
          "children": []
        }
      ]
    },

    }
  ]
}
